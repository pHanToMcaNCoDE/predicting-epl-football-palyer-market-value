# Predicting EPL Football Player Market Value Using Position-Specific ML Models

An end-to-end data engineering and machine learning framework designed to evaluate and predict football player valuations across the top five European leagues. This project eliminates uniform evaluation bias by implementing position-specific modeling pipelines.

## 📊 The Core Infrastructure
* **Data Sources**: Extracted and compiled rich multi-source structural performance profiles from FBref and Transfermarkt.
* **Architecture**: Engineered modular Python ETL data scripts moving raw sports telemetry into optimised data frames.
* **Machine Learning Stack**: Benchmark evaluation of Linear Regression, Random Forest, and tuned XGBoost architectures.

## 💻 Tech Stack & Tooling
* **Languages**: Python, SQL
* **Data & ML Engineering**: Pandas, NumPy, Scikit-Learn, XGBoost
* **Development Workflows**: Git, Modular Python Execution Frameworks

## ⚙️ Model Evaluation & Insights
The project processes performance indicators relative to specific pitch positions (e.g., progressive carries for wingers vs. progressive passes/interceptions for central midfielders) rather than generalised scoring biases.
